# LinkedIn post

Prerequisite: skill `author-profile`.

## Post format (to `drafts/<slug>/linkedin.md`)
- 900 to 1,300 characters. First 2 lines are the hook (before "see more").
- One idea. One real detail. 3 short takeaways. One question. Link to the story in the first comment (offer both options).
- Line breaks every 1 to 2 sentences are fine on LinkedIn. No emoji spam (max 2). 3 hashtags max.
- Voice: first person, humble, practical.
- Variants: story promo, lesson learned, project demo, career note.

- Surname: "Iqbal" (profile shows "Iqbal Awan"). Ask which he wants.
- Featured: pin best Medium story, portfolio, one GitHub demo.

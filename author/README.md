# author/

Everything an AI agent needs to know about the author. Read in this order:

1. `facts.json`: confirmed facts (machine readable, also served by the MCP server).
2. `voice.md`: how he writes and the hard rules.
3. `goals-and-strategy.md`: audience, pillars, distribution.
4. `stories-index.md`: what is already published.
5. `questions-for-author.md`: what is still unknown. Ask, never guess.

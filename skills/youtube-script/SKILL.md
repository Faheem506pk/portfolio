# YouTube script

Prerequisite: skill `author-profile`. Channel today: Technical MFI (1.4K subs, mixed old topics). Ask whether to rebrand or start a dev channel before the first dev video.

## Output (to `drafts/<slug>/youtube.md`)
1. 3 title options (under 60 characters, searchable keyword first).
2. Thumbnail text idea (max 4 words) and visual suggestion.
3. Hook (first 15 seconds): the problem or the result, shown on screen.
4. Script in two columns: **Say** and **Show** (screen, code, diagram). Short spoken sentences, plain English.
5. Chapters with timestamps (estimated).
6. Description: 2 line summary, links (portfolio, Medium story, GitHub repo), chapters, tags.
7. Pinned comment and a call to action (subscribe, read the story).
8. Recording checklist: what to prepare, which repo, which commands.

## Rules
- Only demonstrate things the author actually built or will run live. No fake results.
- Length: 6 to 12 minutes for tutorials, under 60 seconds for Shorts.
- Language: ask if English only or English plus Urdu. Keep code terms in English.
- Credit tools and libraries. Link official docs.
- No em dashes in text he will paste.

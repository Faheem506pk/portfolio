# Medium Editorial System

When reviewing, rating, fact-checking, or refining a Medium article, read and follow the repository-root `SKILL.md`.

Mandatory behavior:
- Be extremely critical but constructive.
- Balance personal developer storytelling, professional technical journalism, and conversational practical explanation.
- Optimize for authenticity, originality, technical accuracy, and engagement.
- Review first and suggest changes. Never rewrite the source file until the user explicitly approves.
- Use the weighted rubric and publication verdict in `SKILL.md`.
- Verify technical claims using primary documentation, official repositories, and release notes. Cite URLs in the review report.
- Do not invent personal experiences, benchmarks, tests, quotations, or credentials.
- Do not treat AI detectors as proof of authorship.
- Save review reports separately under `reviews/`; save approved revisions as new files.
